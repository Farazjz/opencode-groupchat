A group-chat plugin for OpenCode

OpenCode (opencode.ai, the anomalyco/opencode agent) ships a powerful V2 plugin API with exactly the primitives a multi-agent group chat needs: persona agents, slash commands, an event stream, session-level hooks and message injection. This is a working plugin — opencode-group-chat — that adds Hermes-style rooms where several agents take turns on one shared project, hand the floor to each other, and call DONE when the goal is met.

☑ Every group-chat need maps to a public plugin API

Group-chat needOpenCode plugin primitiveWhat the plugin does
Distinct participantsctx.agent.transformregisters each persona as an agent (update() upserts new agents) with its own system prompt
Open & manage roomsctx.command.transformadds the /group slash command: start, stop, status, transcript, add, remove
Capture what was saidctx.event.subscribe()session.step.started attributes messages; session.text.ended carries the full text
Turn-taking enginectx.session.hook("experimental.idle")runs when the session has no pending input — admits the next turn in the same execution
Give the floorctx.session.switchAgent(...)re-points the session at the next persona before its turn
Prompt the next turnctx.session.synthetic(...)injects the turn prompt (room header, transcript tail, rules) with metadata tags
Room persistencectx.storagerooms + transcripts survive restarts; /group resume continues a restored room

📦 Install — macOS, Linux & Windows

Option A — macOS & Linux

Local plugin, no publishing needed; resolved from your project.

mkdir -p .opencode/plugins
cp -r opencode-group-chat \
  .opencode/plugins/group-chat
🪟 Option B — Windows

Native PowerShell / CMD — no WSL required.

# PowerShell, from your project root
git clone https://github.com/Farazjz/opencode-groupchat.git

New-Item -ItemType Directory -Force `
  -Path ".opencode\plugins" | Out-Null
Copy-Item -Recurse -Force `
  ".\opencode-groupchat" `
  ".\.opencode\plugins\group-chat"

opencode   # that's it

CMD equivalent: xcopy /E /I /Y opencode-groupchat .opencode\plugins\group-chat

Install for all your projects: copy into %USERPROFILE%\.config\opencode\plugins\group-chat instead.

Option C — from npm

Publish once, then reference it in opencode.json.

npm i -g opencode-group-chat

// opencode.json
{ "plugin": ["opencode-group-chat"] }
Where plugins live (all platforms)
  • This project only: <project>\.opencode\plugins\group-chat
  • All your projects (global): %USERPROFILE%\.config\opencode\plugins\group-chat (Windows) · ~/.config/opencode/plugins/group-chat (macOS/Linux)

💡 Running OpenCode inside WSL? Use the macOS/Linux steps and keep the plugin inside the WSL filesystem — WSL can't reliably load plugins from Windows paths like C:\…  ·  💡 Your terminal's current directory is the project: .opencode\plugins is always relative to where you launch opencode.

⌨ Commands

CommandEffect

/group resumeContinue a room restored after a restart
/group stopClose the room and restore your previous agent

⇄ How it compares to the Hermes agent

Hermes rooms

A gateway owns the room log and drives turns between bots, even across machines; Desktop renders the room.

This plugin

One OpenCode session is the room: the plugin drives turns between persona agents, so they share full history and can edit the same files.

Shared idea

Explicit hand-offs, a DONE marker, bounded turns, and a transcript you can inspect — the discipline that makes group chat converge.

Built on public APIs from anomalyco/opencode (dev branch) — no forks, no patches.
